# Automated File Organizer (Python)

## Problem
Manually organizing files is time-consuming and inefficient.

## Solution
This Python script automatically organizes files in a folder based on their file type.

## Tech Stack
- Python 3
- os module
- shutil module

## Features
- Organizes Images, Videos, Documents, Audio
- Creates folders automatically
- Easy to customize

## How to Run
1. Place files inside `sample_folder`
2. Run:
   python organizer.py
3. Files will be organized automatically

## Use Case
- Desktop cleanup
- Downloads folder management
- Automation practice
